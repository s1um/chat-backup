# 썰 백업기

카카오톡·트위터 DM·트위터 멘션·밴드 채팅 로그를 붙여넣으면 채팅 UI로 변환해주는 도구입니다.  
설치 없이 브라우저에서 바로 사용할 수 있으며, 모든 처리는 로컬에서 이루어져 개인정보가 외부로 전송되지 않습니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| **로그 자동 파싱** | 카카오톡·트위터 DM·트위터 멘션·밴드 채팅·밴드 댓글 형식을 자동으로 인식 |
| **직접 입력** | 채팅창에 메시지를 직접 타이핑해서 추가 |
| **이미지 첨부** | 사진 버튼으로 이미지 삽입, 클릭 시 라이트박스 확대 |
| **발화자 관리** | 발화자 추가·삭제·이름 변경, 말풍선/이름 색상 커스터마이징, 프로필 사진 업로드 |
| **메시지 편집** | 말풍선 호버 → 편집(연필 아이콘) 또는 더블클릭으로 인라인 수정 |
| **HTML 백업** | 채팅을 독립 실행 HTML로 내보내기(클립보드 복사 또는 파일 다운로드), 다시 불러오기 가능 |
| **PNG 저장** | 채팅 영역을 고해상도(2×) 이미지로 저장 |
| **반응형** | 모바일에서도 사용 가능 (컨트롤 패널 드로어로 표시) |

---

## 사용 방법

### 1단계 — 로그 종류 선택

오른쪽 컨트롤 패널 상단의 탭에서 붙여넣을 로그 종류를 선택합니다.

| 탭 | 지원 형식 |
|----|-----------|
| **카카오톡** | `[이름] [오전/오후 H:MM] 메시지` |
| **트위터 DM** | 탭 구분 또는 `이름: 메시지` + 타임스탬프 블록 |
| **트위터 멘션** | 닉네임 → `@아이디` → · → 시간 → 내용 (닉네임을 발화자로 인식) |
| **밴드 채팅** | 이름(단독 줄) → 메시지 / `yyyy.mm.dd hh:mm 이름` → 메시지 |
| **밴드 댓글** | 이름 → (한줄소개) → 내용 순서의 밴드 댓글 블록 |

탭 아래 힌트 박스에서 정확한 포맷을 확인할 수 있습니다.  
트위터 멘션은 말풍선 대신 트위터(X) 스레드 형태(아바타·`@아이디 · 날짜`·반응 아이콘)로 표시되며, `@아이디`·시간·조회수/반응 수는 자동으로 걸러 붙여줍니다. 잠긴 계정 배지가 있으면 이름 옆에 🔒 표시가 붙습니다.  
트위터 멘션 탭에서는 발화자 칩의 `@` 버튼으로 발화자별 아이디(@핸들) 표시를 켜고 끌 수 있습니다.  
밴드 채팅에서 메시지가 `비밀 댓글`로 시작하면 내용은 빈 말풍선으로 처리되고, 이름 옆에 🔒 표시가 붙습니다.  
밴드 댓글에서도 내용이 `비밀 댓글`로 시작하면 텍스트는 지워지고 이름 옆에 🔒 표시가 붙습니다.

### 2단계 — 발화자 설정

로그 속 이름과 **정확히 일치**하도록 발화자 이름을 설정해야 파싱이 정상 작동합니다.

1. **발화자 선택** 드롭다운 또는 칩을 클릭해 발화자를 선택합니다.
2. **이름 변경** 입력란에 로그 속 실제 이름을 입력하고 `이름 변경` 버튼을 누릅니다.
3. 상대방이 여러 명이라면 `+ 추가` 버튼으로 발화자를 추가한 뒤 이름을 설정합니다.
4. 말풍선 색상(내 쪽은 **말풍선**, 상대방은 **말풍선 + 이름 색**)을 원하는 색으로 변경할 수 있습니다.

> `나`(발화자 0)는 오른쪽 정렬, 나머지는 왼쪽 정렬로 표시됩니다.

### 3단계 — 로그 붙여넣기

하단 입력창을 클릭한 뒤 복사한 채팅 로그를 **붙여넣기(Ctrl+V)** 합니다.  
로그 형식이 인식되면 자동으로 파싱되어 말풍선이 생성됩니다.

- 인식되지 않는 이름이 있으면 하단에 `미등록 발화자: 홍길동` 알림이 표시됩니다.  
  해당 이름으로 발화자를 추가한 뒤 다시 붙여넣으면 됩니다.
- 로그 형식이 아닌 일반 텍스트를 붙여넣으면 현재 선택된 발화자의 메시지로 추가됩니다.

### 4단계 — 편집 및 조정

- **메시지 편집**: 말풍선에 마우스를 올리면 편집(✏) · 삭제(🗑) 버튼이 나타납니다.  
  편집 버튼을 누르거나 말풍선을 **더블클릭**해서 내용을 수정하고 Enter로 확정, Esc로 취소합니다.
- **이미지 추가**: 하단의 이미지 버튼(📷)을 클릭해 사진을 첨부합니다.

### 5단계 — 내보내기

| 버튼 | 동작 |
|------|------|
| **HTML 복사** | 클립보드에 독립 실행 HTML 복사 → 메모장에 붙여넣고 `.html`로 저장하면 백업 완료 |
| **HTML 파일로 저장** | 독립 실행 HTML 파일(`DM_백업_YYYY-MM-DD.html`)을 바로 다운로드 |
| **PNG 저장** | 채팅 영역을 고해상도 이미지로 저장 (`DM_백업_YYYY-MM-DD.png`) |
| **전체 초기화** | 모든 메시지 삭제 (확인 다이얼로그 후 실행) |

저장한 HTML 파일은 **백업 불러오기** → `HTML 파일 불러오기`로 다시 열 수 있습니다.

## 사용 기술

- 순수 HTML / CSS / JavaScript (의존 라이브러리 없음)
