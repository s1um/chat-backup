썰 백업기

채팅 로그 → 채팅 UI 변환 도구

카카오톡·트위터 DM·트위터 멘션·밴드 채팅 로그를 붙여넣으면 채팅 UI로 변환해줍니다.
설치 없이 브라우저에서 바로 사용할 수 있으며, 모든 처리는 로컬에서 이루어져 개인정보가 외부로 전송되지 않습니다.

주요 기능
파싱
로그 자동 파싱
카카오톡·트위터 DM·트위터 멘션·밴드 채팅·밴드 댓글 형식을 자동으로 인식
편집
메시지 편집 · 직접 입력
말풍선 호버 후 편집 또는 더블클릭으로 수정 / 텍스트 직접 입력 가능
꾸미기
발화자 관리 · 색상 커스터마이징
발화자 추가·삭제·이름 변경, 말풍선·이름 색상 자유롭게 설정
저장
HTML 백업 · PNG 저장
독립 실행 HTML로 내보내기(복사 또는 파일 다운로드) 및 불러오기 / 고해상도(2×) PNG 이미지로 저장
사용 방법
  1. 로그 종류 선택 — 오른쪽 컨트롤 패널 상단 탭에서 카카오톡·트위터 DM·트위터 멘션·밴드 채팅·밴드 댓글 중 선택
  2. 발화자 설정 — 로그 속 이름과 정확히 일치하도록 발화자 이름을 설정 (미등록 이름은 파싱 불가)
  3. 로그 붙여넣기 — 하단 입력창에 복사한 채팅 로그를 Ctrl+V로 붙여넣으면 자동 파싱 (직접 텍스트 작성도 가능)
  4. 편집 및 조정 — 말풍선 호버 또는 더블클릭으로 수정, 이미지 버튼으로 사진 첨부
  5. 내보내기 — HTML 파일로 저장 버튼으로 .html 파일 즉시 다운로드하거나, HTML 복사 후 붙여넣어 저장, PNG 저장 버튼으로 이미지 추출
